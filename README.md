# Revit Volume & Cost — Revit add-in

(Working name: the product's name is not decided yet.)

A Revit add-in (Revit 2022–2027) that reads the concrete quantities of a structural model, element by
element, and sends them to the Revit Volume & Cost website on Save, on Synchronize with Central and on a
manual Sync. It also holds the snapshot classes the website's API compiles against.

Status: v0.1 planning. See `CLAUDE.md` and `BACKLOG.md`. Contributions: see `CONTRIBUTING.md`.

Author: Adnan Almulla @ Killa Design.
